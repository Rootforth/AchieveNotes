# AchieveNotes

AchieveNotes is a Rootforth-maintained derivative of HandyNotes: Achievements for WoW Retail.

Current internal development candidate: 12.1.0.0.3. This candidate modernizes the HandyNotes 12.1 `GetNodes2` node/interaction path while preserving the historical achievement-location dataset. Public distribution is not authorized while the AchievementLocations redistribution boundary remains unresolved.
